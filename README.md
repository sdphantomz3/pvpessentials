![Showcases all the features of the mod.](https://cdn.modrinth.com/data/cached_images/1289ab10e5ddb311ee2c1d815d9c698079f9eabf_0.webp)
| Feature | Description |
|----------|-------------|
| **Armor HUD** | Displays equipped armor and it's durability |
| **Arrow HUD** | Shows your remaining arrows. |
| **Potion HUD** | Displays all the potions available in your inventory. |
| **Misc HUD** | Displays total number of golden apples, ender pearls, cobwebs, and **any** item you want to be tracked from your inventory. |
| **Damage Indicator** | Shows how much damage you took, or gave to the enemy. |
| **Low Fire** | Change the Y position of fire overlay  |
| **No Potion Particles** | Disable potion particles from your screen.  |
| **No Explosion Particles** | Disable explosion particles, making playing crystal pvp less obstructive.|
| **Shield Controls** | Change the Y position of idle shield & blocking shield, rotate shield (side shield). |
